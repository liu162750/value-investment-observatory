# 观察台规则
股票定价只认docs/t1t2-handoff-policy.md和scripts/tier-policy.mjs，旧定价说明全部停用。黄金独立Au99.99口径，16:00前排除当天日线，不套股票算法。股票普通刷新不重算。
大盘标题分别显示月线和周线状态。周线使用最新完整周收盘>20周均线且20周均线>=前周20周均线；通过用红色，未通过或待核验用黄色，不将未知显示为通过。当前周线是独立参考展示，不自动启用尚待确认的三层许可方案。鼠标提示包含周线日期和比较数值；失败下次刷新重试。

## 账户今日涨跌计算

持股数量和剩余现金来自后台已录入账户，仓位权重以包含现金的当前总资产为分母。设当前股票权重为w，今日涨跌小数为r，D=Σ[w×r/(1+r)]，账户今日涨跌=D/(1-D)。这相当于反推昨日股票市值并加入现金，以昨日总资产为分母；不能直接把当前权重乘涨幅当作精确收益。假设持股、现金今日无交易或资金进出；持仓更新不及时则为估算，不能标为券商实际收益。现金不排除，仅现金本身没有股票涨跌。旧行情、缺失行情、未来时间和备用快照不得标为今日涨跌。

## 黄金报价与日线分离

页面当前价来自上金所 graph/quotations（Au99.99延时行情），严格根据delaystr来源时间过滤未来分钟占位，并按交易时段处理夜盘跨日。档位、ATR与均线来自graph/Dailyhq已完成日线，来源日期分别显示。报价相对前一已完成日线收盘计算涨跌，入区距离使用当前报价。接口异常明确标注当前报价未取得和历史收盘参考；日线缓存不能阻止重新获取分时报价。两接口单位均为元/克，不混用黄金期货、国际美元报价或银行积存金价格。

黄金使用独立受授权保护的/api/gold刷新，每30秒检查一次，回到页面及手动刷新时也更新，不等待整页股票与新闻接口。页面初始内容优先用已取得的分时报价；整页其他数据失败时不得把黄金覆盖成旧日线。生产启动日志只记录公开黄金价、来源时间和状态，用于线上核验，不输出账户私密数据。

2026-10-08补充：重要事件只在新闻标题后显示0至7天的小型红底闪动提醒，不显示整块预约列表。黄金主源失败优先尝试同品种Au99.99分时备用源，校验品种和已发生时间；来源请求合并且短缓存120秒以减少限流。失败保留上次有效报价与涨跌幅，标时间；无有效报价时涨跌幅未知，不复用旧日线涨幅。前收盘基准按交易时段区分，日间即使最新日线包含当天也不能拿当天收盘作前收盘；20点后夜盘可使用当日日间收盘。

日线读取失败修复：实时价与历史日线独立。日线失败不得清空已确认买档；历史请求缓存5分钟并合并并发，失败使用上次有效日线或包含至少120条完整日线的公开快照，保留来源日期并明确标注更新失败。不得用只存60条的展示数据重算120条要求的档位。发布时快照也按当前规则重算。

持续恢复和部分失败保护：读取源失败自动重试一次，下一轮继续请求，不缓存失败结果。页面整页请求45秒超时并于失败10秒后重试，黄金35秒超时避免永久占用busy；回到页面同时恢复整页和黄金。部分新闻来源失败保留最后有效结果并标异常；黄金按来源时间合并，较旧整页结果不得覆盖独立黄金新报价。已移除美股栏对应的多余网络任务。量能比较只用已完成交易日，盘中半日成交额不得与完整全天成交额比较并判极致缩量。


技术触价与交易许可独立。达到85%阻止T1，T2优先显示其独立状态并核验预算。旧行情和历史快照不能当实时闪动。新股票必须重新独立复核，不复制别股价格。
